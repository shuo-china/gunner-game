# 鱼系统

按原版 `Fish_manager`、`Fish_Tank`、`Fish_Item`、`Fish_Info_UI`、`Fish_DeletePopup`、`Fish_Draw_Btn`、`New_Fish_UI` 的原生反编译和 `level0` 场景实现。入口沿用原左菜单顺序，从下向上为武器、皮肤、鱼、宠物、转生。

## 玩法与开放

- 正式环境历史到第 4 关显示锁定入口，第 6 关开放，新手引导期间隐藏；测试环境直接开放。
- 鱼缸容量 20 条，13 个等级：D、C、B、A、S、SS、SSS、X、XX、XXX、Z、ZZ、ZZZ。
- 鱼在鱼缸内自由游动。点击查看详情，拖动同级鱼合成高一级，拖到放生区后再确认；放生不返还资源。最高级不能合成。
- 历史达到第20关后显示并开放自动合成，与武器、宠物共用 `autoMergeStage`。第20关前隐藏按钮、拒绝自动命令；旧档已开启的自动偏好仍保留，但不执行合成，手动合成照常。自动合成从最低级开始，依原池顺序选择两条同级鱼；开放后免费，不恢复原 PlusPack 会员购买。
- 每天前 3 次免费；广告开启后再开放 2 次广告抽取。钻石抽取每次 200 钻。普通抽取 D/C/B 的概率分别为 60%/30%/10%，高级抽取 C/B/A 同比例。这是原实际场景覆盖值，非构造器内未使用的 40/30/20/10。
- 广告总开关默认关闭，免费次数用完后隐藏广告抽取入口。无广告 SDK 的正式包不模拟发奖。
- 鱼缸下方的抽取按钮按当前可见数量居中排版：单个按钮居中，两个按钮保持等距；免费次数、广告开关或窗口尺寸变化时自动更新。

所有抽取价格、次数、概率及起始等级在 `assets/scripts/core/EconomyConfig.ts` 的 `fish` 分组中维护；开放条件在 `session/ContentConfig.ts`。

## 战斗与存档

全部持有鱼累计攻击、暴击率、暴击伤害，重复鱼同样计入，没有装备槽。主线、挑战、独立 BOSS、突袭均生效。保持原版浮点幂运算、两位有效数字和中点取偶；暴击率最高显示和结算为 100%，总暴击伤害包含基础 125%。详情显示单鱼附加值。

攻击计算顺序为原武器、模式适用的金币/转生强化、皮肤、鱼、整数截断、装备位升星；突袭再乘弱点，暴击最后按整数百分比乘除并截断。原版尚未接入的遗物和临时增益仍为中性倍率。

鱼作为可选 `fish` 字段保存于现有 v3 存档。旧存档缺少此字段时从空鱼缸开始，不重置钱包、武器或进度；转生保留鱼和图鉴。抽鱼、合成、放生和自动开关先保存完整候选状态并读回确认，再更新内存；保存失败不扣钻、不消耗次数。拖拽和放生确认检查版本，防止删掉数组移动后的另一条鱼。

广告使用独立请求 token，关闭面板、后台、取消、失败、重复/旧回调均不发奖；跨日或时钟回拨的旧请求失效。降低每日配置上限不会使已有次数记录作废。

## 美术与界面

资源位于 `assets/resources/art/fish-system/`：304 个原 UI 节点，71 张原图，13 级头像、游鱼和合成描边，原位图字体及新鱼动画曲线。对应原入口、鱼缸、详情、放生确认、概率和新鱼提示，使用现有线性色彩合成流程。完整界面在首次打开时加载；单独入口字形图集约 3.4 KB。

可重复提取与验证脚本位于相邻工作区：

- `AI-Workspace/Work/v1/tools/convert_original_fish.py`
- `AI-Workspace/Work/v1/tools/validate_original_fish.py`
- 原图像素与场景布局校验结果：`AI-Workspace/Work/v1/qa/fish-20261015/source/validation.json`

原资源验证确认 71 张 PNG 与 Unity 重建源逐像素一致，304 个节点的位置、尺寸、锚点和缩放一致。该结论针对导入资源和布局数据，不代表跨引擎所有运行帧逐像素相同。

## 验证

运行 `npm run check`，覆盖纯逻辑、四模式真实暴击弹、保存失败、广告回调、旧档兼容、真实 UI 拖拽/自动合成/放生、后台取消及入口延迟加载。测试环境游戏 iframe 控制台 `__forestGunner.fish` 提供状态、打开、详情、抽取、合成、放生和自动开关接口；正式环境不暴露这套测试操作。
