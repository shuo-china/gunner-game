|---|---|---:|---|

## 四把推导数值与同阶差异

2026-10-15 恢复原版已有的同阶差异：D 级三把单发弓分别取原版 ID 0（打猎：100、0.6 秒）、1（钢铁：80、0.5 秒）、2（雷电：50、0.3 秒）；C 级两把单发弓取原版 ID 5（魔翼：200、0.6 秒）和 6（金龙：100、0.3 秒）；D 级两把弩取原版 ID 3（弩弓：80/箭、1 秒、2 箭）和 4（特制鹰弩：90/箭、1.1 秒、2 箭）。这四把新增武器 ID 59–62 的战斗数值直接来自原版序列化记录。
