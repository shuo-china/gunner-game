# 设置与音频

本期设置面板仅提供 BGM、Sound 和兑换码。以 Cat Gunner 1.1.61 的 Unity 场景和原生方法为依据；BGM、Sound 在原上排整体居中，兑换入口保持原位置；设置面板按后续反馈收紧底部空白。

设置仍在首次点击时加载。兑换码占位提示和非 ASCII 输入使用系统字体（`sans-serif`），英文和数字输入使用 29,552 字节的 `font317.ttf` 精简字库；95 个可打印 ASCII 字符的轮廓、字宽与原完整输入字体一致，系统中文字形会随设备略有差异。固定面板文字保留原位图字库。原输入模板节点只保留布局，不再创建隐藏文字，也不再加载对应的两张图集；输入字形指标和描边配置仍供实际 EditBox 使用。

设置直接引用的字体与图片合计为 69,559 字节（约 70 KB），较最初的 12,302,198 字节减少约 99.4%，较取消完整中文字体后的 1,753,178 字节再减少约 96.0%。这些是无缓存资源文件体积，不是实测耗时。完整中英文字体、无用数字字体和两张隐藏输入图集已从运行时资源目录移出，旧资料保存在工作区 `AI-Workspace/Work/v1/font-cleanup-20261015/before`。

2026-10-15 发布补齐：0.1.9 沿用的旧发布源码遗漏了上述字体优化，点击设置仍请求完整字库。本次 0.1.10 将字体清理、精简输入与系统中文回退一并合入，并将设置的 8 张图片和 1 个字体放入独立微信分包；经无损压缩为 57,886 字节，分包包含启动脚本为 57,923 字节。加载最多四项并行、失败项自动重试。打包器检查编译后的设置配置，发现完整字体依赖时拒绝出包；同时支持 Creator 的目录形式 TTF 原生路径，避免漏装字体。

无缓存浏览器通过真实设置按钮打开，记录到恰好 9 项、69,559 字节的原生资源；重复打开不新增请求，中英文输入和两种竖屏尺寸通过。最终微信编译模块的设置加载器也单独验证只请求 `font317` 和 8 张图片。实际发布下载钩子组合验证全部 214 项分包原生资源可本地读取，日志与截图见 [本轮交付记录](../../AI-Workspace/Work/v1/qa/settings-release-20261015/DELIVERY.txt)。本地打开耗时不代表手机弱网耗时。

- 提示使用现有 OriginalAlerts，约两秒自动消失；重复提交重启同一提示动画。

## 音频

`OriginalBgm` 使用一个循环音源：Main 播放 `Relaxed_7_BlossomDrift`；SpeedRun、Boss、Raid 播放 `Cute_5_MilkShake`。同曲请求不重播，切换曲目才从新曲开头播放。关闭 BGM 时已播放的曲目通过音量 0 保留进度；存档已关闭 BGM 时不下载或启动音乐。开启后只下载当前模式曲目，另一首等切换模式时加载；重复请求合并，迟到的下载不会切换当前曲目。音乐失败可在设置中重新开启重试。

Sound 启动时只读取轻量配置；开启 Sound 后预热界面点击与已装备武器音效，其余 WAV 在首次使用时下载。相同路径的音效合并请求，关闭 Sound 不发起新下载；下载完成不会补播旧事件。失败请求退避十秒，后续使用可重试。无引用的音效 ID 0、14 已移除，其余 ID、音量和去重规则保留。

运行资源为 44.1 kHz、双声道、128 kbps MP3。原始 FSB 来自 `sharedassets0.assets:287` 与 `:289`，先使用已有 fmod_toolkit 解码，再编码并回解码校验，时长为 121.263 秒和 105 秒。

Sound 在现有 `OriginalSfx.play` 入口拦截新音效，覆盖界面和战斗，保留现有武器素材、音量、同帧去重及冷却。关闭时已开始的短尾音自然结束，与原版 `Sound_manager.PlaySfx` 一致。

浏览器等待首次可信鼠标、触摸或键盘操作再启动音频；不会补播此前被丢弃的战斗音效。进入后台暂停 BGM，返回恢复，重载时销毁旧音源及监听。

## 偏好与兼容

独立存储键为 `forest-gunner:audio:v1:test` / `forest-gunner:audio:v1:production`，内容为 `{version:1,bgmEnabled:boolean,soundEnabled:boolean}`。默认均开启，每次切换立即保存。存储不可用时当前会话仍可切换；字段缺失或损坏按默认值处理。

偏好独立于经济 v3 存档，转生、换装及教程重放不重置声音设置。原版每十秒自动保存，本项目改为立即保存以避免刷新丢失刚切换的偏好。

兑换领取记录为经济 v3 存档的可选 `redeemedCodes` 字段，与钻石余额在同一条存档中原子写入；旧存档缺失该字段时视为未领取，不改变已有资产。沿用测试／正式环境隔离键。写入且读回确认后才更新内存余额和显示成功；存储不可用或余额溢出时保持输入并提示失败。领取记录随刷新及转生保留。
