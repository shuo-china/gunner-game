# 七天钻石领取

每日签到与皮肤、转生入口同步显示：完成新手教程，并成功通关至少一次挑战。主界面的七天钻石入口打开原版七格签到面板。开放后首次可领取第一格，每个本地自然日只能依次领取一格；中断不会重置进度，也不补发错过的日期。领取第七格后，当天保留全部已领取状态，次日从第一格循环。每次启动在满足开放条件后自动提示一次可领取奖励；界面入口仍可手动打开。

## 奖励与配置

奖励统一位于 [`EconomyConfig.ts`](../assets/scripts/core/EconomyConfig.ts) 的 `dailyCheck` 分组：

```ts
dailyCheck: { diamondsByDay: [140, 400, 800, 1200, 1600, 2000, 3000], dailyLimit: 1 },
```

七项为原版 `[70, 200, 400, 600, 800, 1000, 1500]` 的两倍最终值，一轮合计 9140 钻。界面预览和实际到账读取同一份配置，不在领取时再次乘二。奖励允许为零，零奖励仍完成当天领取。`dailyLimit` 仅允许 0 或 1；0 暂停领取，恢复为 1 后继续原进度。

## 状态、到账与旧档

[`DailyCheckSystem.ts`](../assets/scripts/session/DailyCheckSystem.ts) 计算七格状态和领取候选；[`BattleSession.ts`](../assets/scripts/session/BattleSession.ts) 提供 `getDailyCheckState()` 与 `claimDailyCheck(dayIndex)`，下标为 0～6。可领、已领、未轮到分别为 `getable/geted/normal`。查询状态不写存档，不扣除任何资源，也不发放奖励。

v3 存档新增可选 `dailyCheck` 块：`lastClaimDay` 保存本地日期，`checkNum` 保存本轮已领格数，`totalCheckNum` 保存累计领取次数。缺少该块的旧档保留原钱包及其它进度，从第一格可领开始。存在但损坏的块原样保留并禁止签到领取，避免把未知已领记录重置成未领。

会话先把新钻石余额与新领取状态写入同一份完整存档，再读回核对；确认后才更新内存和通知界面。失败不消耗领取资格；写完才抛异常时以读回结果为准。若无法读回，阻止旧内存自动覆盖可能已提交的存档，重启后恢复确定结果。重复点击、重入、同日重启、配置调价都不会再次发放已领格子的奖励。

日期使用现有 `weapons.now`（含测试环境时间推进）的设备本地自然日。回拨到已领取日期或更早时不可再领；前进到后续日期才恢复下一格资格。没有引入原版服务器校时、收益审计账本及韩国 Coupang 外链领取。

## 美术、入口与弹窗

原版节点、贴图、九宫格、字体、按钮反馈、光晕和飞钻参数集中在 [`art/daily-check-system/config.json`](../assets/resources/art/daily-check-system/config.json)，通过现有 `OriginalWeaponUi` 和颜色管线渲染。金额文本由会话状态填充，资源中不保留奖励常量。字体复用现有原版位图字库。原场景金币栏默认隐藏，顶部保留棚布和钻石余额栏。

入口位于设置右侧，与皮肤、转生共用 `ContentConfig.ts` 的 `rebirthSkinChallengeWins`（默认 1）及教程完成条件；未满足时隐藏入口并禁止手动、自动打开，不显示签到红点。挑战失败或中途退出不计入，已有首胜记录可直接满足；测试环境沿用共同的教程与进度绕过规则。轻量入口由 `tools/sync-feature-entries.cjs` 生成；完整资源接入后台预加载、点击按需加载与微信功能分包。下载失败保留自动弹出意图并延后重试，手动点击可立即重试。

启动时有可领奖励则保留一次自动弹出意图，等待教程完成、挑战首胜以及离线收益摘要、其他弹窗和场景过渡结束；同一次启动内达成条件后即可弹出，无需重启。面板打开或加载时阻止底层交互；异步加载完成后再次检查开放条件。后台恢复刷新日期和卡片状态，不重新自动弹出。领取后面板保持打开，固定八颗飞钻飞向面板钻石栏；中途关闭改飞主界面钻石图标，每颗到达播放原音效并触发余额栏弹跳。动效只在确认存档成功后启动，不参与发奖。

## 原版依据

- 原始场景 `data.unity3d` 的 `level0:142665 / DailyCheck.DiaReward_list` 保存七项原始金额；读取时使用原版 DummyDll 恢复类型树并完整校验序列化读取。
- [`DailyCheck__t7261.c`](../../CatGunner-Original/Decompiled/native/Assembly-CSharp/DailyCheck__t7261.c)：`NewUser_Reload` 令首次日期为昨天；`UI_reload` 在领满七格且跨日时归零；`DailyReward_Get` 检查当前格与日期，发放后累计两个计数并保留面板；普通七天领取不调用广告。
- [`DailyCheck_Reward__t7262.c`](../../CatGunner-Original/Decompiled/native/Assembly-CSharp/DailyCheck_Reward__t7262.c)：可领和已领覆盖层互斥，可领格提升绘制顺序。
- [`Time_manager__t7375.c`](../../CatGunner-Original/Decompiled/native/Assembly-CSharp/Time_manager__t7375.c)：原版 `Today` 为本地自然日，同时依赖独立的受信任时间与收益账本；当前项目按已确认范围使用本地日期规则。
