# 内容解锁与环境配置

## 新手主引导

`TutorialManager` 保存教学步骤，`TutorialHud` 显示提示，`ContentUnlockManager` 继续管理功能开放条件。正式新档默认开启，普通测试档默认跳过；步骤为 `upgrade → challenge → gunOpen → gunBuy → gunEquip → done`。

皮肤使用 `getContentState('skins')`，教学完成状态由会话传给管理器的 `tutorialCompleted` 提供；未开放时返回 `reason: 'tutorial'` 和“完成新手引导后开放皮肤。”。会话购买、装备返回 `contentLocked`，拒绝时不扣钻、不写档。当前存档已购但未完成教学时保留所有权、外观及加成，只限制新操作；教学字段缺失或损坏时拒绝恢复，不自动视为完成。

| 步骤 | 当前行为与完成条件 |
| --- | --- |
| `upgrade` | 金币足够购买时，猫爪指向攻击升级；成功购买一次、攻击等级达到1后进入下一步 |
| `challenge` | 攻击等级不足3且金币足够时，猫爪继续指向升级；达到Lv.3后显示挑战入口，没有单独的挑战猫爪。首次挑战胜利后进入下一步 |
| `gunOpen` | 提示打开武器面板；首胜只解锁入口，并正常结算120钻 |
| `gunBuy` | 首次实际打开已解锁的武器面板时，仅将不足100的钻石补足到100；正常首胜的120钻保持不变，抽一把100钻武器后剩20钻。关闭重开不重复发放，背包获得有效武器后进入下一步 |
| `gunEquip` | 提示将背包武器装备到第二格；完成有效换装后结束主引导，已完成的装备操作也会被识别 |
| `done` | 主引导完成，不因刷新或转生重新播放 |

详情、图鉴、概率、升星、新枪弹窗、广告和手动拖拽优先处理，主引导提示暂避；关闭武器面板后可重新打开继续当前步骤。步骤及成功抽取次数随当前 v3 存档持久保存，缺少教程字段时拒绝恢复，不跳过主引导。

合成教学保持独立：首次合成前，背包中有两把未锁定、非广告占位的D级枪才显示合成箭头。主引导进行中暂时隐藏该箭头，并暂停自动合成动画；完成后恢复原有条件。当前首胜120钻够抽一把枪，余20钻，不额外赠送合成材料，也不要求合成才能结束五步主引导。

## 修改配置

```ts
CONTENT_CONFIG.ads.enabled // 当前为false：全广告隐藏并禁止请求及结算；true：按条件开放
CONTENT_CONFIG.ads.placements // 十一个广告位当前均为true，可在总开关下单独关闭
CONTENT_CONFIG.production // 正式环境的解锁门槛
CONTENT_CONFIG.test.bypassProgression // 测试绕过门槛；资源数量在 EconomyConfig.ts
CONTENT_CONFIG.tutorial // production默认true，test默认false
ECONOMY_CONFIG.onboarding.firstDrawDiamondFloor // EconomyConfig.ts：首次打开武器面板的钻石补足值，默认100
```

修改 `ads.enabled` 或各广告位开关后，重新构建即可应用广告入口规则。广告模块只负责展示、互斥、取消和完成结果，广告开关放在内容配置中，避免入口和广告服务各维护一套值。环境仍由构建参数 `-Environment test/production` 选择，存档隔离。

当前没有接真实广告SDK。测试包使用模拟面板；正式包使用不可用提供者，返回失败、不发奖。后续接SDK只需替换正式提供者，不能把测试模拟成功按钮带到正式包中。

Raid（突袭）的 `raidStage: 40`、`raidVisibleStage: 35` 使用相同的显示关卡口径。每日本地00:00刷新免费/广告使用状态，每周本地周一00:00更换突袭首领并重置周任务；时钟回拨不补次数。跨周局不打断，奖励与历史记录正常结算，本周次数/成绩不记入新周。这些配置只属于突袭，与独立 Boss 玩法分开。详情见 [Raid说明](Raid说明.md)。

独立 Boss 使用 `bossStage: 10`、`bossVisibleStage: 6`，分别对应历史值90与50。`getContentState('boss')`返回入口显示和解锁状态，`bossAd`额外要求广告位 `boss` 开启；实际加奖还需本次胜利。Boss无每日、每周或付费入场限制，转生保留独立进度和历史解锁条件。详见 [BOSS说明](BOSS说明.md)。

## 测试环境重放引导

测试包在游戏运行页的调试控制台提供以下API，不需要修改正常测试存档：

```js
__forestGunner.tutorial.state() // 当前 { active, step }
__forestGunner.tutorial.preview // 当前是否为隔离引导预览
```

## 当前存档要求

当前 v3 必须包含 `content` 块，保存 `challengeUnlocked`、`weaponsUnlocked`、`firstDrawGranted` 三个布尔值。新档执行正式引导门槛；已有存档缺块或值非法时拒绝恢复并禁止覆盖原档，不推断入口与首次补给状态。

首次挑战奖励与武器解锁一起保存；首次打开武器面板时，按 `EconomyConfig` 补足必要钻石，首次补给标记与教学步骤一起保存，余额已足够时只保存标记。之后重启、关闭重开、转生、再次挑战不会重复补足。必填 `tutorial: { step, drawCount }` 保存主引导步骤和成功抽取次数；缺块、缺计数或值非法时拒绝恢复。转生不清除教学步骤。`autoEnabled` 继续保存，实际使用仍受环境和入口门槛控制；不维护旧的限时自动合成字段。

关闭广告后，旧存档中未领取广告枪的占位和计时会清理；已领取的真实武器不动，也不会补发未领取枪。保留已经触发过活动的记录，避免反复开关重复触发。广告关闭时首次合成不会消耗尚未触发的活动机会。

独立 Boss 使用必填 `boss: { stage }`，与普通挑战 `speedRun` 和突袭 `raid` 分开保存。Boss 胜利奖励和下一关在同一次保存提交，金额以 `EconomyConfig` 为准，转生不清除；已有存档缺失或损坏该块时拒绝恢复并禁止覆盖原档。广告 token 不持久化，刷新及退出后迟到回调不能加奖。钻石产出调整不会追补已有余额或已领取奖励。
