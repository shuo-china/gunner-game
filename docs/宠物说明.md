# 宠物系统

玩法接入最初基于 Cat Gunner 1.1.61 的 ARM64 反编译实现、Unity 序列化场景及 Spine 4.1.24 资源。2026-10-23 已将十种可用宠物的头像、完整身体贴图及 Idle/Walk 动画数据全部换为本轮新制作版本；下文原始资源名称仅用于历史追溯。宠物已接入狩猎产出的宠物币、每日广告宠物及旅行派遣；现金付费和推广入口不在实现范围。自动合成免费，广告默认关闭。原版资料目录保持只读。

## 玩法规则

历史最高进度换算为显示关卡 `floor(stageValueMax / 10) + 1`。第 10 关显示锁定入口，第 12 关开放；主教学期间隐藏，转生保留历史解锁、库存、装备和发现记录。测试环境沿用项目统一的关卡绕过策略，不向宠物库存或宠物币发放测试资源。

背包 16 格，装备位 3 个，正式新档均为空，宠物币为 0。100 钻石或 100 宠物币获得 D 阶宠物；背包满或余额不足不扣款。狩猎每清一小关立即获得30宠物币。每日广告宠物挂接统一广告位 `pet-daily`，首次清完任意狩猎小关后满足进度条件，广告开启时默认每天领取一只C阶。满包、取消、失败、跨日或过期回调不消耗次数；价格、品质与次数统一读取 `EconomyConfig.ts`。

点击宠物显示详情，可翻页查看十阶属性。同阶背包宠物二合一，ZZZ 不再合成。新发现某阶时播放一次原版新宠物弹窗。背包拖拽使用原卡片缩小 40 的重叠检测，优先最近的重叠宠物；否则落到最近空格（含起始格）。异阶交换时被挤开的宠物移到最近空格；装备位之间可交换，背包拖到装备位替换并保留原宠物。装备拖回背包区域或点击卸下时放入首个空格，满包则保持装备。

历史达到第20关后显示并开放自动合成，与武器、鱼共用 `autoMergeStage`；默认关闭，开放后免费切换。第20关前隐藏按钮、拒绝自动命令，旧档已开启的偏好保留但暂停执行，手动合成照常。按阶级从低到高、背包序号从前到后选第一对，只使用低于已发现最高阶、且低于 Z 的材料，即最高自动把 SSS 合为 Z。运动用原版 0.25 秒 SmoothStep、25 单位触发距离和 0.12 秒间隔；关闭、拖拽、弹出详情、后台、暂停、尺寸变化、解锁条件变化及过期资源回调均取消当前操作。取消不移动库存、不扣钱。

仅装备位参与属性：金币按装备位顺序累加原 `OriginalInfVal` 百分比后加基础 100，再进入现有奖励运算；不转为普通 JS 浮点数。例如 D、D、ZZZ 的原版有效位规则得到总倍率 46100%，不擅自补精度成 46104%。移速为 `100 + 装备宠物移速之和`，与历史关卡加速相乘。重复宠物可叠加，全部卸下恢复宠物基础倍率 100%。宠物没有攻击、碰撞伤害或额外奖励事件。

## 接口、存档和资源加载

`PetSystem` 提供纯库存操作、`PetSave` 与不可变副本 `PetSnapshot`。HUD 只读快照并发命令；`BattleSession` 提供 `drawPet`、`movePet`、`equipPet`、`unequipPet`、`mergePets`、`setPetAutoMerge` 和 `getPetState`。所有变更先操作候选库存，与钻石钱包组成一份完整 v3 存档写入并回读确认，然后发布内存状态。重入、写失败和过期回调不会重复扣款或丢宠物；回读不可用时阻止后续自动覆盖可能已落盘的记录。

v3 存档增加可选 `pets`：`owned[16]`、`selected[3]`、`collected[10]`、`coins`、`autoEnabled`、`lastDailyAdDate` 和可选 `dailyAdCount`（旧档当日已领取迁移为1次）。槽位空值为 -1。缺失块按空库存恢复，损坏宠物块不抹除有效金币、武器、关卡等其他进度。保留 `forest-gunner:economy:v3:production` 与 `forest-gunner:economy:v3:test` 隔离。

入口达到显示条件后加载轻量 `feature-entries/pets`，首次打开加载完整 `pet-system/config` 与字体、图片。动画只加载当前装备或准备装备的阶级，资源完整校验加载成功且快照版本未变时才提交换装。准备期间关闭面板、后台或加载失败均不改变装备。

`PetAnimation` 继续复用 `OriginalParticleMesh` 渲染。当前简约无腿 v4 每只使用一张完整透明图和 10×6 连续加权网格，耳、尾、翅膀、耳羽等按局部权重单独摆动。Idle 为轻微呼吸，Walk 为轻跳与摆动，没有脚部骨骼；保持用户确认的完整轮廓，局部运动不产生拆件接缝。保留 0.2 秒过渡、场景缩放/旋转/偏移与存档 ID。普通圆形地面阴影仍复用共享的几何贴图。旅行营地使用相同的十套动画。
